First time on this iPhone? One-time setup

Add the free shortcut once. After that, scanning the sign and tapping Start is all it takes.

Get the Laundry Timer shortcut
  1. Open the Shortcuts app and tap +.
  2. Name it exactly Laundry Timer.
  3. Add the action Get Numbers from Input and set it to Shortcut Input.
  4. Add the action Start Timer, tap its number, and pick Numbers. Leave the unit as minutes.
  5. Tap Done, come back here, and tap Start. The first time, Safari asks to open Shortcuts.

Nothing is sent anywhere. The timer runs on your own phone.

Writing the NFC tag
  1. Get NTAG213 or NTAG215 stickers and the free NFC Tools app.
  2. Copy the link above. In NFC Tools, tap Write, then Add a record, then URL (or Custom URL for a shortcuts: link).
  3. Paste the link, tap Write, and hold the sticker to the top of your phone.
Fastest: tap the tag, timer starts
  1. On your iPhone, open Shortcuts, then Automation, then +, then NFC.
  2. Tap Scan and hold your phone to the machine's tag.
  3. Choose Run Immediately, then add Start Timer and set the minutes.

Each regular sets this up once on their own phone. After that, a tap on the tag starts the timer with no screens at all. Any NFC sticker works for this, written or not.
