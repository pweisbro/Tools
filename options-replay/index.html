Options Replay

Simulation only · past data

Replay one past trading session minute by minute and try option plays with paper money, by hand or with an agent. Nothing here can place a real order: there is no broker connection, and the only money is the starting cash you type in. Data comes from MarketData.app with your own token, or from a built-in demo day.

Day to replay

The token stays in this browser (localStorage) and is sent only to api.marketdata.app. Each day costs about — requests the first time; answers are cached here so a replayed day is free afterwards. Replays must be at least one day old.

        How the simulation works

        The clock steps through the stock's 1-minute bars. Option prices come from each contract's own bars (1- or 5-minute). An order placed at minute t fills at the open of the first option bar after t, plus slippage against you, plus commission. Positions are long only and are marked at the latest option close; nothing is exercised at the end of the day. f′ and f″ use the same least-squares quadratic as Options Watch. An agent is a function that gets what a trader could see at that minute and returns paper orders; the built-in momentum rule shows the shape, and the Claude agent sends that view to the Messages API with two tools, paper order and note. Your own rules work the same way: the Strategy card turns a plain-English description into a small rule set, reads it back, and the replay runs it exactly. Every finished run lands in the Trials table. The export is the whole trial as JSON, including the rule set, for scoring agents against each other. The staged plan toward anything beyond paper trading is in PLAN.md; nothing live exists.
