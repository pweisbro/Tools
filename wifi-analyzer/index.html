Wi-Fi Analyzer

How strong your Wi-Fi is and which bands and channels are crowded. The scan runs on your own computer; nothing is uploaded or saved by this page.

A web page can't see nearby Wi-Fi, so a small script does the scanning. With Python installed, run python wifi_scan.py serve from this folder for a live view, or python wifi_scan.py scan --json scan.json and open the file here. Download the script · setup notes
